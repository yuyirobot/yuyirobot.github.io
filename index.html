本网站是鱼易ESP烧录工具，可用于将固件应用程序烧录到通过 USB 串口连接的 ESP32 设备。

该工具有两种使用模式：

  • 快速开始：4个简单步骤 - 插入、连接、选择内置固件镜像、烧录！
  • DIY：对于高级用户，使用您自己的预构建固件镜像从本地存储烧录！
您甚至可以构建并发布您自己的应用程序，用于 ESP32 使用 ESP Launchpad。

Quick Start

ESP 目前提供了一些内置的固件，可以烧录到 ESP32 设备上。您可以选择内置的固件应用程序，并根据芯片类型进行选择。 只需将您的 ESP32 设备插入串行 USB 端口。使用菜单中的连接选项连接到您的 ESP32 设备。从内置固件示例集中选择固件。点击烧录！

固件将被烧录到您连接的设备上。您可以在控制台窗口中查看固件烧录的进度。

这个简单的四步过程将固件烧录到连接的设备上，并使其按您的需求运行。

DIY

您可以使用 ESP IDF 工具构建自己的固件二进制文件。这些固件镜像可以从本地计算机烧录到连接的设备上。只需将您的 ESP32 设备连接到串行 USB 端口。使用基于 Web 的工具连接到您的设备。然后，您可以从计算机的本地存储中选择固件应用程序。选择要烧录固件的内存地址。固件可以是单个文件，也可以是一组要烧录到特定内存地址的多个文件。

点击烧录！

固件将被烧录到您连接的设备上。您可以在控制台窗口中查看固件烧录的进度。
